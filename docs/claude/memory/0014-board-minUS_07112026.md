# 0014 — New board `hardware/minUS_07112026/` (owner, 2026-11-07) and its review

**Status:** design under review (not fabricated) · type: project · source: netlist via kicad-cli + `nets.py`
(session 09 log, 2026-11-07 section). Refs below are the **new** designators (they changed vs minUS_10102026).

## What it is
Slim board: RP2354A U8 + PIC32AK1216GC41048 U9 + **BGA2817 LNA U2** + **SN74HC4052 U1** gain mux; 5 V IRLML
totem pulser (Q1/Q2, TC4427 U3) on net `Transducer` (SMA RF3, IPEX RF1, H5); RX on net `TRANSDUCER` (SMA RF22,
IPEX RF23/24, H10/H11). Removed: AD8338/AD8331/AD8432/OPA847/LMH6629, MCP4531/4131/4728, MD1213/TC6320, MD0100.
Chain: TRANSDUCER → C3 → U2 → C32 → R69/R70 (RX_NODE) → C40 → OA1 (Rf via U1 1Y0–3: 2.2k/4.7k/6.8k/10k; Rg R28 1k
+ C43) → C1 → OA2 (U1 2Y0–3 same values; R30 + C44) → R67/C86/R68/C87 → PIC32_ADC (pin 5 AD1AN9, BAT54S D1).
Taps: LNA = AD1AN1 (pin 10), OA1OUT = AD1AN0 (8), OA2OUT raw = AD2AN1 (16).

## Review verdict (2026-11-07)
Aligned with memory 0013: separate RX net, Vmid on both IN+, gain-leg caps, interstage C, no digipot, LNA.
**Must fix:** RP_GC1/RP_GC2 (U1 S0/S1) are local labels → floating; C3 330 pF into 50 Ω → HP 9.6 MHz (use 10 nF);
R17 4.7 k vs R18 10 k on MCLR → 1.05 V low (R17 → 0 Ω; RP is the only programmer now); D2 BAV99 clamps to
GND/AVDD (−0.6…+3.9 V) > LNA ±1 V → antiparallel to GND, series R/T-R if TX and RX nets are joined.
**Should:** R69/R70 → 0 Ω / 51 Ω; one Rf → 0 Ω for ×1; DNP Cf OUT→IN− (mux C on IN−); anti-alias C 56 → ~100 pF
(~6 MHz); move PIC32_ADC to an ADC2 pin (4 AD2AN9 / 24 AD2AN8) for dual-gain capture; R8 0 Ω AVDD=DVDD → ferrite;
R65/R66 on OA2OUT unneeded. Gain: paired steps 20/30/36/42 dB + LNA 24 dB = 44–66 dB.

## Follow-ups (2026-11-07, after the review)
- **C3 330 pF is too small:** HP 9.6 MHz into 50 Ω → −14 / −9 / −7 dB at 2 / 3.5 / 5 MHz (and pulse
  differentiation). → **10 nF** (HP ≈ 320 kHz, −0.1 dB at 2 MHz). 330 pF came from the BGA2817 note "≤ 100 pF
  above 100 MHz; increase below 100 MHz".
- **C32 must become 10 nF too** once R69/R70 → 0 Ω/51 Ω (it would then see 51 Ω → same 9.6 MHz corner).
  C40 and C1 (into 10 k) stay 330 pF.
- **Optional 100 nF series cap before D2** (owner idea): 0.45 Ω at 3.5 MHz, blocks DC. Useful when `Transducer`
  and `TRANSDUCER` are joined (pulser may idle at +5 V → D2 would conduct into AVDD). Needs a **1–10 kΩ bleed to
  GND** at the D2 node (else the node between the caps floats), D2 antiparallel to GND (diodes reset the cap on
  each edge), ≥ 50 V X7R (≥ 100 V if HV returns). Not a T/R switch: the TX edge still passes.
- Proposed input: `TRANSDUCER` → 100 nF → [1–10 kΩ to GND] + [BAV99 to GND, ±0.6 V] → C3 10 nF → BGA2817 →
  C32 10 nF → 51 Ω to GND (R70) → C40 330 pF → OA1 IN+ (Vmid via R37).
