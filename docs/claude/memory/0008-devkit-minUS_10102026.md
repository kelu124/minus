## Inter-MCU links (netlist-verified)
UART (RP GPIO16/17 ↔ PIC RC7/RP40, RC6/RP39), SPI (RP GPIO2–5 master ↔ PIC RD1/RD2/RC2/RD0
client), I²C shared bus (GPIO0/1 ↔ RD8/RD7 + OLED/digipots/DAC), TRIG (GPIO6 → RA0),
RDY (GPIO7 ← RA7). **Start with UART** (simplest, tapped on H2.7/8 for sniffing).

## RP control over the PIC
- **Reset:** GPIO24 → R53 4.7k → MCLR node (R5 10k pull-up, C31 470n via solder jumper JP1,
  R9 442R → pin 48, J1.1 direct).
- **ICSP:** GPIO21 → R56 0R → PGC1 (RB4), GPIO22 → R57 0R → PGD1 (RB3); same pins on J1
  (Tag-Connect, Microchip ICSP pinout) via 47R, and J1 pins 4/5 also carry RP SWCLK/SWDIO
  (R17/R18 0R). ICSP is 2-wire bit-bang (DS70005583 §2–3): entry key 0x8A12C2B2, 2-bit
  commands, 32-bit shifts → **feasible from RP GPIO/PIO; not written yet.**

## Flaws found 2026-10-26 (must fix on the board)
1. **R68‖R69 = 50 Ω between SPI_MOSI and SPI_MISO** (MCP4131 SDI/SDO coupling done too
   strong) → keep ONE resistor at 1–4.7 kΩ (removing both kills digipot writes).
   **Bus ownership: RP is the only digipot master (SPI MCP4131, I²C MCP4531/MCP4728); PIC
   SPI/I²C pins stay Hi-Z.**
2. **GPIO24 cannot reset the PIC:** R53 4.7k vs R5 10k → MCLR ≈1.05 V > VIL 0.66 V →
   fit R53 = 0 Ω; cut JP1 to remove C31 for ICSP.
3. **JTAG default-on hijacks SPI pins** (TCK=RD1, TDO=RD2, TMS=RB1) → `JTAGEN=OFF` in
   config; a blank PIC won't talk SPI.
4. PGC/PGD shared with RP SWD (47 Ω) — keep GPIO21/22/24 Hi-Z unless programming.
5. U5 (WS2812) + LED1 (SK6812) DIN in parallel on GPIO10, 5 V parts at 3.3 V logic (marginal).
6. PIC has no crystal (OSC pins only on H2) → runs on FRC 8 MHz ±1.5 %.

## PIC toolchain facts (verified 2026-10-26)
- Compiler = **MPLAB XC-DSC** (≥ 3.31.01 lists `32AK1216GC41048`; current 4.00, free/no key).
  Device support = **`Microchip.PIC32AK-GC_DFP`** (1.1.53, packs.download.microchip.com),
  unpacked at `~/microchip/packs/PIC32AK-GC_DFP/1.1.53/` — files live under `xc32/` inside
  the pack; pass `-mdfp=<pack>/xc32` (fallback: pack root). Flashing = `ipecmd` from
  **MPLAB X 6.35** (tar → `.sh` installer, `/opt/microchip/mplabx/v6.35`).
- Header check: `U1CONbits.{MODE,RXEN,TXEN,BRGS,ON,CLKSEL,CLKMOD}`, `U1STATbits.{TXBF,RXBE}`,
  `RPINR9bits.U1RXR`, `RPOR9bits.RP39R`, `RPCONbits.IOLOCK`, `PACCON2bits.RPCONWR`,
  `ANSELAbits.ANSELAn`. Config pragmas: `JTAGEN=OFF`, `WDTEN=SW|HW`, `WINDIS`, `ALTI2C1/2`,
  `SPI2PIN`, `BISTDIS`, `ICSPPED` — **no `ICS` setting** in this family.
- Programmers supported for this part (MPLAB device-support list, MPLAB X ≥ 6.25): **Snap,
  PICkit Basic, PICkit 4/5, ICD 4/5, ICE 4** (debug + program); not Atmel-ICE/EDBG/PM3.
- **Owner decision 2026-10-26: programmer = MPLAB Snap or PICkit Basic** (ipecmd codes `SNAP`,
  `PKBASIC`). MPLAB X 6.35 installed at `/opt/microchip/mplabx/v6.35` (also carries the DFP);
  **XC-DSC 3.31.01 installed** (`/opt/microchip/xc-dsc/v3.31.01`); udev rule
  `z010_mchp_tools.rules` present. **`firmware/pic32` builds** (hex ~7 kB). XC-DSC gotchas:
  pass `-T <DFP>/xc32/support/PIC32A/gld/p<dev>.gld` explicitly, `xc-dsc-bin2hex -mdfp=…`,
  no `xc-dsc-size` (read the .map). MPLAB X's 97 packs = 8 GB → disk filled once.
- **`STEP1.md`** (repo root) = board fixes + install + test procedure for the link test.
