# `acq` (4095-sample ADC capture PIC32AK → RP2354) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `acq` on the RP2354 USB console makes the PIC32AK capture 4095 raw 12-bit ADC samples of
AD1AN9 at a nominal 40 Msps and prints them, one per line, with the measured fill time.

**Architecture:** PIC side (XC-DSC, bare metal): PLL to 160 MHz CPU / 320 MHz ADC at boot; on
`ACQ` an SCCP1 time-base rollover triggers ADC1 channel 0 every 25 ns, DMA0 moves each
`AD1CH0DATA` into a 4095 × u16 RAM buffer, Timer1 measures the fill, then the PIC sends a text
header + 8190-byte little-endian payload over UART1. RP side (pico-sdk C): `acq` command sends
`ACQ`, parses the header (host-testable pure function), drains the payload with deadlines, prints.
`tools/rpcli.py` gains `--out=FILE`.

**Tech Stack:** XC-DSC 3.31.01 + PIC32AK-GC_DFP 1.1.53 (`make -C firmware/pic32`), pico-sdk 2.1.0
(`PICO_SDK_PATH=/home/kelu/projets/pico-sdk`, CMake + Ninja), Python 3 for rpcli and host tests.

**Spec:** `docs/claude/specs/2026-10-27-acq-design.md`

## Review Focus

1. PIC absent/blank (no header within 500 ms): `acq` must print `acq: no reply from PIC` and the
   next `ping` must work — Task 3 test `acq_parse` + drain-until-idle behaviour.
2. Header arrives but payload short (PIC reset mid-send): `acq: short payload, got X of 8190 bytes`
   and nothing printed as data — Task 3.
3. `ACQ 4095 … timeout` header (DMA never finished): print the status line, no payload read — Task 3
   parse test with `status=timeout`.
4. Slow-but-completing DMA (fill > 819 µs): Timer1 prescaler 1:8 range 6.5 ms ≥ 5 ms deadline so
   `ticks` cannot wrap — Task 2 (value pinned in code, checked by review).
5. `--out=FILE` with an unwritable path must not swallow the console reply — Task 4 test.

### Task 2: PIC `ACQ` capture (ADC1 + SCCP1 trigger + DMA0 + Timer1) and protocol v2

**Files:**
- Create: `firmware/pic32/acq.c`, `firmware/pic32/acq.h`
- Modify: `firmware/pic32/main.c` (command dispatch, `ID?` proto), `firmware/pic32/version.h` (`PROTO_VERSION 2`), `firmware/pic32/Makefile` (`SRC := main.c acq.c`)

**Interfaces:**
- Produces (`acq.h`):
  ```c
  #define ACQ_N        4095u
  #define ACQ_TRIG_DIV 4u              // CLKGEN12 160 MHz / 4 = 40 MHz trigger; 8 -> 20 Msps
  #define ACQ_TICK_NS  100u            // Timer1: FPB 80 MHz / 8 prescaler
  typedef enum { ACQ_OK = 0, ACQ_TIMEOUT, ACQ_DMAERR, ACQ_NOTREADY } acq_status_t;
  void         acq_init(void);         // ADC1 on + ADRDY, CH0 config, DMA module on, Timer1 config; called once after clocks_init()
  acq_status_t acq_run(uint32_t *ticks);   // one capture into acq_buf; ticks = Timer1 count at DMA DONE
  extern uint16_t acq_buf[ACQ_N];
  ```
- Consumes: `FPB` from Task 1; `uart1_putc/uart1_puts` in `main.c`.

- [ ] **Step 1: `acq_init()`** — `ANSELAbits.ANSELA9=1; TRISAbits.TRISA9=1;`
  `AD1CONbits.ON=1; while(!AD1CONbits.ADRDY);`
  `AD1CH0CON=0; PINSEL=9; MODE=0; SAMC=0; DIFF=0; TRG1SRC=12 /*SCCP1 trigger out*/;`
  `CCP1CON1=0; MOD=0; T32=0; CLKSEL=1 /*CLKGEN12*/; TMRPS=0; SYNC=0; CCP1PR=ACQ_TRIG_DIV-1;` (ON stays 0)
  `T1CON=0; TCS=0; TCKPS=1 /*1:8 (T1CON[5:4]: 00=1:1, 01=1:8, 10=1:64, 11=1:256)*/; PR1=0xFFFF;`
  `DMACONbits.ON=1; DMALOW=0x4000; DMAHIGH=0x7FFF; DMA0SEL=0x2B /*ADC1 CH0*/;`
- [ ] **Step 2: `acq_run()`** — if `!AD1CONbits.ADRDY` return `ACQ_NOTREADY`.
  `IFS2bits.DMA0IF=0; DMA0STATbits.DONE=0; DMA0SRC=(uint32_t)&AD1CH0DATA; DMA0DST=(uint32_t)acq_buf; DMA0CNT=ACQ_N;`
  `DMA0CH=0; SIZE=1; SAMODE=0; DAMODE=1; TRMODE=0; CHEN=1;`
  `(void)AD1CH0DATA; /* clear a stale ready flag */ CCP1TMR=0; TMR1=0; T1CONbits.ON=1; CCP1CON1bits.ON=1;`
  poll `DMA0STATbits.DONE` with a bounded loop ≥ 5 ms at 160 MHz (e.g. 800 000 iterations);
  `CCP1CON1bits.ON=0; T1CONbits.ON=0; *ticks=TMR1; DMA0CHbits.CHEN=0;`
  return `ACQ_TIMEOUT` if not done, `ACQ_DMAERR` if `DMA0STATbits.ADRERR` set, else `ACQ_OK`.
  Timer wrap guard: 6.5 ms range > 5 ms deadline (Review Focus 4).
- [ ] **Step 3: Command** — in `main.c`: `else if (!strcmp(line, "ACQ")) { uint32_t t; acq_status_t s = acq_run(&t); snprintf(out, "ACQ %u %lu %u %s\n", ACQ_N, t, ACQ_TICK_NS, s==ACQ_OK?"ok":s==ACQ_TIMEOUT?"timeout":s==ACQ_DMAERR?"dmaerr":"notready"); uart1_puts(out); if (s==ACQ_OK) for i<ACQ_N: putc(lo), putc(hi); }`.
  `PROTO_VERSION 2` in `version.h`; the `ID?` reply follows automatically.
- [ ] **Step 4: Build + RAM check** — Run: `make -C firmware/pic32 2>&1 | tail -3 && grep -E "acq_buf|\.bss|\.data" firmware/pic32/build/minus_pic.map | head`. Expected: hex written, `acq_buf` 0x1ffe bytes, total data+bss+stack < 0x4000.
- [ ] **Step 5: Commit** — `git add firmware/pic32 && git commit -m "feat(pic32): ACQ — 4095-sample ADC1 capture via SCCP1 trigger + DMA0, proto 2 (fw 0.1.1)"`
