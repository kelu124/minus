# 2026-11-23 — session 14: envbp filter notebook (offline)

Board not plugged in. Owner asked to illustrate the PIC32's Gaussian band-pass envelope ("brings 60 dB") on recorded
`.npz` data, raw signal behind and filtered data in front, by simulating the PIC filtering in Python, as a notebook.

## What was done
- `python/notebooks/05_envbp_filter.ipynb` (generated, executed offline with
  `jupyter nbconvert --to notebook --execute --inplace python/notebooks/05_envbp_filter.ipynb`).
- Input: `docs/bench/2026-11-22-datasheet-ext/envbp.npz` (rp 1.1.9 / pic 1.1.6, proto 15, board 3, Annex A transducer,
  gain ×3.2): 16 raw `pe_ref` shots (dt 40.20 ns) + the PIC's own `envbp 8 {1,16} 25 fc bw` outputs (5 runs each) + `env`.
- `pic_envbp()` = line-by-line port of `firmware/pic32/pe_ext.c: pe_envbp` (σ_f = FWHM/2.3548, σ_t = 1/(2πσ_f), ±3σ_t taps
  capped at 32, cos/sin taps, mean removal, evaluation at block centres j·dec+dec/2, scale 2·16/Σg, rounding to 1/16 LSB,
  integer shot averaging).

## Results (3.3 MHz / FWHM 2.5 MHz, dec 8 → 23 taps, σ_t 150 ns)
| envelope | echo pk (LSB) | floor rms (55–78 µs) | pk/floor |
|---|---|---|---|
| raw \|x−mean\| | 492 | 3.46 | 44.7 dB |
| env 8, PIC measured (×π/2) | 534 | 4.25 | 43.8 dB |
| envbp simulated, 1 shot | 498 | 0.75 | 56.5 dB |
| envbp PIC measured, 1 shot | 463 | 0.73 | 56.0 dB |
| envbp simulated, 16 shots | 489 | 0.67 | 57.3 dB |
| envbp PIC measured, 16 shots | 475 | 0.68 | 56.8 dB |

Pulse peak / floor of the envbp envelope ≈ 66 dB (shot 0: 66.1 dB). So the "60 dB" is: ~56 dB first-echo/floor,
~66 dB full envelope range; the filter's gain over `env` is ~+12 dB. Simulation matches the firmware within ~0.5 dB
(different shots of the same session). Other filters: 3.3/1.5 57.9 (PIC 56.8), 3.3/4.0 52.8 (54.5), 4.0/4.0 49.9 (48.3) dB.
16-shot averaging adds only ~1 dB → the remaining inter-echo floor is mostly repeatable in-band signal.
An out-of-band burst at ~135–145 µs in the raw RF (~25 dB above floor) is removed entirely by the filter.
