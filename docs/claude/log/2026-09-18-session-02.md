## PIC32A + RP2350 concept

- Owner raised: pair a **Microchip PIC32AK3208GC41064 (PIC32A)** with the RP2350 —
  PIC32A op-amps as the gain stage, its ADC to capture ~150 µs A-lines, transfer to
  RP2350 which preprocesses + exposes over USB; RP2350 could even flash the PIC.
- Verified the part from the family product brief (DS70005582, mirrored to
  `pdfs/datasheets/`): **2× 12-bit ADC up to 40 Msps**, **3× 100 MHz rail-to-rail
  op-amps** (100 V/µs), 3 comparators + 12-bit DACs, HS-PWM (2.5 ns) w/ ADC trigger,
  PTG, 3.0–3.6 V, 200 MHz FPU/DSP core, ~32 KB flash / ~16 KB SRAM, 64-pin, **no USB**.
- Wrote `design/pic32/README.md` as a trade study. Key finds:
  - **Relevant:** the on-die 40 Msps/12-bit ADC + 100 MHz op-amps clear P2/P3/P4 with
    margin and **collapse the external ADC (ADEC) + external VGA into one chip** —
    also removes the hardest baseline task (PIO-clocked external-ADC capture). 150 µs
    fits SRAM (6 KB @20 Msps / 12 KB @40 Msps).
  - **No USB on the PIC** is the clean justification for keeping the RP2350 as the
    open USB front-end + DSP + UF2/ICSP programmer (one USB-C port boots both).
  - **Main tension: anti-req N1** — PIC32A needs Microchip MPLAB/XC (closed) toolchain,
    unlike RP2350 pico-sdk. Mitigation: ship a prebuilt PIC image the RP2350 flashes;
    only PIC-firmware hackers need the closed tools. Also: fixed op-amps ≠ true VGA
    (TGC needs a scheme), second-MCU firmware complexity, DP4/DP5 tension, and LCSC
    stock/price TBD (N2).

- **Price/availability check.** Digikey lists `PIC32AK3208GC41064-I/PT` (TQFP-64,

  DP2 win, cheaper than the baseline ~$16 active-IC set. **Caveat:** Digikey ≠ LCSC;
  **LCSC/JLCPCB availability still unconfirmed** (N2) — must verify before locking.
- **Corrected SRAM to 8 KB** (was assuming ~16 KB). Redid capture math: 150 µs fits at
  20 Msps (6 KB) but **not** at 40 Msps (12 KB) → PIC grabs one line ≤8 KB and bursts
  out; RP2350 buffers longer/multiple lines.
- **Owner decision: TGC not needed.** Gain doesn't vary within a line; the user just
  **sets a fixed gain and can change it between firing lines**. Big simplification
  (no fast DAC ramp, no gain/depth timing sync).
- **Gain-stage design (new §3b in `design/pic32/`).** PIC32A op-amp gain is set by
  external feedback R (no confirmed internal PGA ladder — verify). To make it settable
  between lines: **digipot/MDAC in feedback** (recommended, ~$0.5–1, = the owner's "DAC
  controls gain" done right — gain lives in a resistor ratio, so use a digital resistor,
  not a DAC voltage), or a **resistor-mux** (cheapest, stepped), or an external VGA/PGA.
  Owner's **LNA-first** idea captured as optional A3a: a fixed low-noise front stage
  ahead of the settable gain, for weak 5 V-pulser echoes.
- **requirements.md updated:** F6 → [M] per-line settable gain (TGC explicitly not
  required); A3 rewritten; A3a (optional LNA) added; P8/A1/§17 de-TGC'd.

## PIC32A chip choice + RP2350 interconnect (new §3c, §3d)

- **§3c chip choice.** Family = **36 / 48 / 64-pin** (VQFN/TQFP), flash/RAM tiers
  **32 KB/8 KB (`3208`) … 128 KB/16 KB (`1216`)**; pins and memory are independent axes.
  Pin-budget estimate (~12–16 pins) → **48-pin is the safe sweet spot**, 36-pin
  borderline, 64-pin generous (unneeded since RP2350 owns the 40-pin header).
  **Program memory:** firmware is small → **flash ~32 KB is ample**; the real lever is
  **SRAM** (8 KB → 150 µs @20 Msps; 16 KB → 150 µs @40 Msps). Recommend starting with
  `PIC32AK3208GC41048`.
- **§3d interconnect.** RP2350 = master/programmer, PIC = capture engine. Signals:
  **ICSP** (`MCLR`/`PGC`/`PGD`, LVP per DS60001145; `MCLR` doubles as reset) so one
  USB-C port programs both; **SPI** (SCK/MOSI/MISO/CS) for the A-line burst; **RDY** IRQ
  (PIC→RP2350); **TRIG** (RP2350→PIC ADC ext-trigger for TX/RX sync); optional **UART**
  debug/log; shared **3V3**. Minimal set = 9 lines; ICSP pins can be reused at run time.

## RP2354A flash + BOOTSEL (from local rp2350-datasheet.md)

- **Confirmed RP2354A needs no external flash:** 2 MB in-package flash (stacked Winbond
  W25Q16JVWI die), QFN-60, pin-identical to RP2350A, 30 GPIO / 4 analog. Caveat:
  QSPI_IOVDD must be 3.3 V. Extra QSPI flash/PSRAM can still be added via a Bank-0 GPIO CS.
- **BOOTSEL button:** QSPI pads (incl. QSPI_CSn/SS) are still bonded out; BOOTSEL =
  QSPI_CSn driven low at reset/power-up. So the button wires **QSPI_CSn → GND via ~1 kΩ**
  (same as a flashless RP2350A/Pico), optionally paired with a **RUN reset button**
  (hold BOOTSEL, pulse RUN) to avoid a power cycle. Captured in `design/pic32/` §3c.
