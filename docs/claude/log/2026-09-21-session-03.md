# Session 03 — 2026-09-21

## RX gain path clarification

- Q: in the RP2354A + PIC32A designs, does the LNA go straight into the ADC, or do we use
  the PIC32 op-amps for gain, and how is gain set?
- A: **PIC32A on-die op-amps do the gain** (no dedicated LNA in the cheap build; ADC is
  internal to the PIC). Chain: piezo → MD0100 T/R → OA1 fixed (+14.5 dB) → OA2 variable
  (6–42 dB) → OA3 bias → 2-pole RC AAF → PIC ADC. **Gain set by an I²C digipot
  (MCP4531-103)** as OA2's gain resistor — firmware writes the wiper code once per line
  (no TGC). External LNA (A3a) optional; "LNA straight to ADC" is a fixed-gain alternative
  we didn't pick.

## Devkit (DesignA-DK)

- Owner wants a **devkit**: RP2354A + PIC32AK, with **swappable front ends** (LNA/gain on
  top of the PIC op-amps), **many breakouts** (space no constraint), to **derisk** decisions.
- Wrote **`design/devkit/README.md`**. Philosophy: every contested choice = swappable
  daughter-card / populate-option / jumper, with an SMA tap at every node — measure, don't
  guess.
  - Core spine: RP2354A + **PIC32AK6416GC41064 (64-pin / 16 KB)** (no pin/RAM limits),
    split AVDD/DVDD rails w/ current-sense, both programming paths, all pins broken out.
  - **Modular RX front-end** on a standard mezzanine header: FE-0 straight → FE-A PIC-opamp
    → FE-B LNA+PIC-opamp (AD8432/LMH6629/OPA847) → FE-C AD8331 → FE-D AD8338; ADC-src
    jumper picks {PIC op-amp / direct / ext-VGA}.
  - **Gain-control options:** MCP4531 (I²C) / MCP4131 (SPI) / resistor-mux (74HC4052) /
    VGA Vgain via DAC or RP2354 PWM — compare.
  - **Pulser bench:** push-pull or single-FET, HV-rail select (5V/boost/ext, MD1213 pads),
    damping options, JP1 drive-select, MD0100/BAV99 T/R.
  - **Measurement:** SMA taps + test points everywhere; loopback self-test mux (DAC inject).
  - **Derisk priority:** (1) PIC32A ADC reality, (2) FE noise/LNA need, (3) pulser
    edges/amplitude, (4) digipot BW, (5) inter-MCU + toolchain. Do the silicon-level ones
    **first on Microchip Curiosity + GP-DIM** and a Pico 2 before/alongside the custom board.
  - Path back to DesignA: down-spec winners to the cheap 48-pin `3208` badge.
- Added mermaid architecture diagram; linked from `design/README.md`.

## Devkit revision: single board, jumper-selected (no mezzanine)

- Owner: **no mezzanine connectors** — one board with all FE blocks populated, **jumpers
  select the path**. Reworked `design/devkit/`:
  - Common **RX node** → each FE taps via `JIN_*`, drives the **ADC node** via `JOUT_*`;
    fit one JIN+JOUT pair to pick a path (FE-0 straight = one link). Unused blocks left
    un-jumpered (isolated). Keep JIN links at the RX node to minimise RF stubs.
  - Gain-control choice via an on-board **jumper block** (I²C/SPI digipot, resistor-mux,
    VGA Vgain) — nets run to all candidates.
  - Down-spec to DesignA = **depopulate losing blocks + hard-wire chosen jumpers** (no
    daughter-cards to carry over). Updated mermaid + design/README.
