# Session 03 — 2026-09-21

## RX gain path clarification

- Q: in the RP2354A + PIC32A designs, does the LNA go straight into the ADC, or do we use
  the PIC32 op-amps for gain, and how is gain set?
- A: **PIC32A on-die op-amps do the gain** (no dedicated LNA in the cheap build; ADC is
  internal to the PIC). Chain: piezo → MD0100 T/R → OA1 fixed (+14.5 dB) → OA2 variable
  (6–42 dB) → OA3 bias → 2-pole RC AAF → PIC ADC. **Gain set by an I²C digipot
  (MCP4531-103)** as OA2's gain resistor — firmware writes the wiper code once per line
  (no TGC). External LNA (A3a) optional; "LNA straight to ADC" is a fixed-gain alternative
  we didn't pick.

## ADC input conditioning + TX-coupled acquisition + datasheet

- **Q (ADC range):** PIC32AK is single-supply → ADC **0→VREF (~3.3 V) single-ended**
  (LSB ~0.8 mV; differential limited ~±VREF/4). 0-centred ±2 V RF must be **AC-coupled,
  biased to mid-rail (1.65 V, via OA3), scaled to ~2.6–2.8 Vpp** (not fed bipolar), with
  an overrange clamp; per-line digipot gain = auto-range. Captured in DesignA **§5a**.
- **Q (tight TX↔ADC coupling):** yes — PIC HS-PWM that drives the pulser also emits the
  **ADC trigger off the same counter** (~2.5 ns, zero jitter); **PTG** for coded bursts;
  ADC **window/gate** mode. Needs **PIC-owns-TX** (JP1) for tightest; RP2354-owns-TX routes
  pulse-start into the PIC ADC ext-trigger (TRIG). Captured in DesignA **§5b**.
- **Docs updated:** DesignA §5a/§5b (+ tidied a duplicate digipot bullet); pic32 §4
  (ADC input range + ADC↔TX trigger) & §3d; requirements **A5** (single-supply input
  conditioning) + **C1c** (hardware-coupled ADC trigger); devkit derisk-map rows for
  ADC-conditioning and TX↔ADC-trigger.
- **Datasheet kept + converted:** downloaded **DS70005592 full datasheet** (36 MB) and
