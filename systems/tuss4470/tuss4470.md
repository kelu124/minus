# TUSS4470 (front-end IC route)

**Full name:** TI TUSS4470 — direct-drive ultrasonic sensor AFE with logarithmic amplifier
**Year:** 2021 (IC); BOOSTXL-TUSS4470 EVM
**Origin:** Texas Instruments (commercial IC; open eval + community designs around it)
**Status:** commercial IC, public datasheet + EVM (not an open board, but a documented building block)
**References:** ti.com/product/TUSS4470 ; datasheet SLASEV3 ; BOOSTXL-TUSS4470
**Repository:** — (TI EVM: MSP-EXP430F5529LP + BOOSTXL-TUSS4470)
**License:** commercial (datasheet public)
**One-line summary:** Single-channel integrated ultrasonic AFE — H-bridge/FET pre-driver TX plus LNA + bandpass + log-amp RX with analog envelope out; the "analog-envelope front-end IC" route (cf. PuLsE).

> Included as a *building-block/IC-class* reference, not a full imaging system.
> Aimed at industrial ToF (30 kHz–1 MHz), so it is a low-frequency, envelope-only
> option — relevant to the minimal/low-power end of the design space.

## 10. Notes / constraints / relevance to *minus*

- Represents the **integrated analog-envelope front-end IC** route: TX H-bridge +
  LNA + log-amp + envelope in one chip. Same architectural branch as PuLsE, but as
  an off-the-shelf part — potentially the cheapest, lowest-part-count option.
- Hard limits for imaging: 30 kHz–1 MHz band and envelope-only output (no RF phase,
  no matched filtering/Doppler) rule it out for higher-frequency medical B-mode.
- For *minus*: attractive if the target is envelope/ToF-class sensing at ≤1 MHz;
  ruled out if raw RF or >1 MHz imaging is required. See [[pulse]].
